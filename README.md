# Smaakquiz voor wijnhandelaars

White-label demo: zes vragen, drie voorgestelde wijnen, daarna een bestel- of reserveerstap.

- [Stijl 1 — Editorial wijn](stijl-1.html)
- [Stijl 2 — Licht & modern](stijl-2.html)
- [Stijl 3 — Klassiek & warm](stijl-3.html)

De drie stijlen delen dezelfde vragen en hetzelfde assortiment.

## Eigen assortiment

Vervang de wijnen in `wines.js` (de array `WINES`, plus eventueel `SHOP` en `REGIONS`). Eén bestand volstaat voor alle stijlen. Prijzen die nog niet bekend zijn, zet u op `€ —`.
